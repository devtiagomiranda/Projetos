Quem sou eu?

Olá, tudo bem? Eu me chamo Tiago Miranda dos Santos, tenho 20 anos e sou estudante do curso de Desenvolvimento de Software Multiplataforma na FATEC Jaú. Nascido e criado em São Paulo, mudei-me para Jaú aos 11 anos. Minha trajetória na área de tecnologia começou em meados de 2024, após terminar o ensino médio, quando iniciei o curso técnico em Desenvolvimento de Sistemas na ETEC de Jaú. Atualmente, estou no primeiro semestre da graduação e busco uma oportunidade na área de desenvolvimento para continuar aprendendo e evoluindo a partir da resolução de problemas reais.

Projetos

Site de Autopeças

Desenvolvi o site para uma loja de autopeças utilizando HTML, CSS e JavaScript. O projeto conta com uma seção de apresentação, catálogo completo de produtos, área de contatos com a localização da empresa e um carrinho de compras funcional, onde as peças selecionadas pelo cliente são adicionadas diretamente.

Site de Cadastros

Desenvolvi um sistema web de cadastros chamado CentralCad, utilizando HTML, CSS e JavaScript. O projeto inclui uma tela inicial de apresentação, um formulário completo para registro de clientes (com campos para nome, e-mail, CPF, telefone, setor e observações) e uma aba de listagem, permitindo consultar, editar e excluir os registros realizados.
